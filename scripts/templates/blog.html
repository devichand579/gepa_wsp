01 / THE QUESTION

From prompt evolution
to weight programs.

Weight-Space Programming explores LLMs reading and writing neural weights. GEPA uses reflection and selection to improve prompts. Our question was whether the same loop could improve programs that construct network weights.

We allowed full training arrays, weights, forward activations, statistics and closed-form fits. We excluded parameter-gradient and Newton updates in approved selected programs. This is learning from data through generated statistical code; it does not demonstrate coefficient construction without numerical fitting.

The useful result is improvement through reflection.
The interesting question is what did the learning.

Diffusion setup and Adam baseline

MNIST resized to 16 × 16 and scaled to [−1, 1]. The network concatenates the noisy image and t/31, then applies 3 × 3 convolutional layers 2 → 32 → 64 → 64 → 1 with ReLU. The cosine schedule uses s = 0.008 and clips beta at 0.999; sampling clips the reconstructed clean image.

Training noise seeds: 81,000 + seed; selection: 82,000 + seed; fresh held-out noise: 83,000 + seed. Adam used batch size 64, 1,000 steps and two development-selected learning rates, 1e−3 and 3e−4. Clean-image pools and initial targets were shared. See implementation and protocol.

01 Propose edit(w, f)→02 Sandbox & paired feedback→03 GEPA selection↻

Each program runs with Python, NumPy and math, without project files, credentials or network access. Limits are 60 CPU seconds and 4 GiB; execution is repeated to check determinism. Parameter keys, shapes, float32 dtype, finite values and magnitude ≤ 1,000 are checked.

Classification uses the composite development objective 0.9 × correct + 0.1 × p(true label). Diffusion uses negative MSE. This implementation jointly edits the parameter dictionary and disables crossover; it does not test independent per-layer modules.

Repair before final tests

Eight original conditions contained parameter-gradient or Newton updates. We excluded their full trajectories and ran fresh constructions with the same model, data, seed and budget. Nemotron diffusion seed 0 required a second replacement after an unnamed gradient was found.

Freeze, inspect, evaluate

All 45 selections were frozen. Every one of the 115 distinct selected-lineage source programs passed recorded inspection before final testing. All original and replacement API costs remained charged.

Preserve the evidence

The condensed repository includes every reported metric, 45 endpoint checkpoints, 12 Adam baselines, review decisions and repair records. Intermediate checkpoints and generated program sources remain in the original Git commit and local archive.

Inspection has limits. A static screen cannot prove the absence of arbitrary optimizer implementations. The final gate included source inspection of every selected program. The protocol and method screen were amended during repairs; older completed conditions retain their original prompt. These amendments are disclosed, and the fresh compact classification comparison shares the amended prompt.

09 / WHAT WE CAN SAY

Evidence for a loop.
Still questions about the mechanism.

Supported by these runs

  • Reflection and selection can improve or repair one-shot statistical weight programs on these small tasks.
  • Generated programs can compile useful classifiers into fixed neural-network containers.
  • Reliability and construction failures materially affect the apparent gains.
  • Diffusion remains far behind Adam in denoising error and qualitative samples.

Still unestablished

  • An advantage caused specifically by GEPA's Pareto selection.
  • A general replacement for Adam, or a win at matched FLOPs and data exposure.
  • Learning attention or useful features in every nominal layer.
  • A reliable LLM ranking, scaling to large networks, or useful diffusion generation.

We used three seeds per condition and reused the same held-out split across seeds. Seed standard deviations do not capture all LLM uncertainty. Per-example paired intervals and unadjusted McNemar p-values in the raw data are conditional analyses, not corrected evidence across all comparisons. Public-dataset familiarity from LLM pretraining cannot be ruled out. Some internal validation in generated statistical fits is not nested and can overfit the training pool.

THE NEXT EXPERIMENT

Separate reflection from the fitter.

Add greedy reflection, random proposals and a hand-written statistical fitting baseline, then match data exposure and internal compute. Use novel tasks and architectures where the generated program cannot bypass the mechanism we want to study.
